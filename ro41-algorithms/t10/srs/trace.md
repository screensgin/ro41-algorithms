# СРС 10. Трассировка поиска и сортировок

## 1. Сортировка выбором для a = {5, 2, 9, 1, 7}

Алгоритм на каждом проходе $i$ ищет минимальный элемент в оставшейся части массива от $i$ до $n-1$ и меняет его местами с элементом `a[i]`.

| Проход $i$ | Индекс минимума | Массив после обмена | Число сравнений на проходе |
| :--- | :--- | :--- | :--- |
| $0$ | $3$ (значение `1`) | `{1, 2, 9, 5, 7}` | $4$ |
| $1$ | $1$ (значение `2`) | `{1, 2, 9, 5, 7}` | $3$ |
| $2$ | $3$ (значение `5`) | `{1, 2, 5, 9, 7}` | $2$ |
| $3$ | $4$ (значение `7`) | `{1, 2, 5, 7, 9}` | $1$ |

* **Общее число сравнений:** $4 + 3 + 2 + 1 = 10$.

## 2. Сортировка вставками для a = {4, 3, 2, 1}

| Шаг $i$ | `key` | Число сдвигов | Массив после вставки |
| :--- | :--- | :--- | :--- |
| $1$ | `3` | $1$ | `{3, 4, 2, 1}` |
| $2$ | `2` | $2$ | `{2, 3, 4, 1}` |
| $3$ | `1` | $3$ | `{1, 2, 3, 4}` |

* **Сколько всего сдвигов:** $1 + 2 + 3 = 6$ сдвигов.
* **Сколько сравнений выполнит алгоритм на уже отсортированном массиве из 4 элементов:** На уже отсортированном массиве внешний цикл делает $3$ итерации ($i$ от $1$ до $3$). На каждой итерации происходит ровно $1$ сравнение элемента с предыдущим (`key < a[i-1]`), условие оказывается ложным, и сдвигов не происходит. Всего будет выполнено **$3$ сравнения**.

## 3. Бинарный поиск

### А) Поиск x = 7 в массиве `{1, 3, 5, 7, 9, 11, 13}`

| Шаг | `lo` | `hi` | `mid` | `a[mid]` | Решение |
| :--- | :--- | :--- | :--- | :--- | :--- |
| $1$ | $0$ | $6$ | $3$ | $7$ | `a[mid] == 7`, элемент найден на индексе `3` |

### Б) Поиск x = 6 в том же массиве

| Шаг | `lo` | `hi` | `mid` | `a[mid]` | Решение |
| :--- | :--- | :--- | :--- | :--- | :--- |
| $1$ | $0$ | $6$ | $3$ | $7$ | `6 < 7`, смещаем `hi = mid - 1 = 2` |
| $2$ | $0$ | $2$ | $1$ | $3$ | `6 > 3`, смещаем `lo = mid + 1 = 2` |
| $3$ | $2$ | $2$ | $2$ | $5$ | `6 > 5`, смещаем `lo = mid + 1 = 3` |

* **Чем закончится поиск:** Поиск завершится неудачно, так как `lo > hi` (`3 > 2`), элемент `6` отсутствует в массиве.
* **Какое значение вернет `LowerBound(6)`:** Метод `LowerBound(6)` вернет индекс `3` (первый элемент массива, который больше или равен `6`, это число `7` на индексе 3).
