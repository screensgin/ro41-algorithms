# СРСП 1. Перевод секунд в часы, минуты и секунды

## Описание проекта
Консольное приложение на C#, которое принимает на вход целое неотрицательное число секунд и конвертирует его в часы, минуты и секунды. Реализована защита от некорректного ввода (текст, дробные или отрицательные числа) без аварийного завершения программы.

| Входные данные | Ожидаемый результат | Фактический результат | Статус |
| :--- | :--- | :--- | :--- |
| **3725** | 1 ч. 2 мин. 5 сек. (01:02:05) | 1 ч. 2 мин. 5 сек. (01:02:05) | Успешно |
| **59** | 0 ч. 0 мин. 59 сек. (00:00:59) | 0 ч. 0 мин. 59 сек. (00:00:59) | Успешно |
| **86399** | 23 ч. 59 мин. 59 сек. (23:59:59) | 23 ч. 59 мин. 59 сек. (23:59:59) | Успешно |
| **0** | 0 ч. 0 мин. 0 сек. (00:00:00) | 0 ч. 0 мин. 0 сек. (00:00:00) | Успешно |
| *-150* | Ошибка: отрицательное число | Ошибка: количество секунд не может быть отрицательным. | Успешно (перехвачено) |
| *abc* | Ошибка: неверный формат | Ошибка: введено некорректное значение. | Успешно (перехвачено) |

## Инструкция по запуску
1. Откройте терминал в папке проекта.
2. Запустите команду: `dotnet run`
3. Введите число секунд при запросе программы.
