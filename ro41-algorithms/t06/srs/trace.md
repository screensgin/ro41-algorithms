# СРС 6. Трассировка сдвига и разворота массива

## 1. Циклический сдвиг влево на одну позицию
Исходный массив: `a = {4, 1, 7, 3, 9}`, длина $n = 5$.  
Буфер сохраняет первый элемент: `buffer = a[0] = 4`.

### Таблица трассировки сдвига
| Шаг | Индекс $i$ | Действие | Состояние массива $a$ |
| :--- | :--- | :--- | :--- |
| Инициализация | — | `buffer = a[0]` | `{4, 1, 7, 3, 9}` |
| 1 | $0$ | `a[0] = a[1]` | `{1, 1, 7, 3, 9}` |
| 2 | $1$ | `a[1] = a[2]` | `{1, 7, 7, 3, 9}` |
| 3 | $2$ | `a[2] = a[3]` | `{1, 7, 3, 3, 9}` |
| 4 | $3$ | `a[3] = a[4]` | `{1, 7, 3, 9, 9}` |
| Завершение | — | `a[4] = buffer` | `{1, 7, 3, 9, 4}` |

## 2. Разворот массива на месте
Исходный массив: `a = {4, 1, 7, 3, 9}`, $n = 5$.  
Цикл обмена элементов `a[i]` и `a[n - 1 - i]` выполняется для $i$ от $0$ до $\lfloor n / 2 \rfloor - 1$ (то есть при $n=5$ цикл идет для $i = 0$ и $i = 1$).

* **$i = 0$:** обмен `a[0]` (4) и `a[4]` (9) $\rightarrow$ массив принимает вид `{9, 1, 7, 3, 4}`.
* **$i = 1$:** обмен `a[1]` (1) и `a[3]` (3) $\rightarrow$ массив принимает вид `{9, 3, 7, 1, 4}`.
* При $i = 2$ условие продолжения цикла становится ложным, работа завершается.

* **Количество обменов:** выполнено **2 обмена**.
* **Почему цикл идет только до $n / 2$:** Если бы цикл продолжался до конца массива ($n - 1$), то во второй половине элементы поменялись бы местами обратно, вернув массив в первоначальное состояние. Проход ровно до середины гарантирует, что каждый элемент первой половины меняется с симметричным элементом второй половины ровно один раз.

## 3. Ошибка в поиске минимума при `min = 0`
* **Суть проблемы:** Если переменная для поиска минимального значения инициализируется фиксированным числом `0` вместо первого элемента массива `a[0]`, алгоритм некорректно работает на массивах, состоящих только из положительных чисел.
* **Пример массива, на котором алгоритм ошибается:** `a = {5, 2, 8}`.
  * Если условие проверки выглядит как `if (a[i] < min)`, то ни один элемент положительного массива `{5, 2, 8}` не окажется меньше `0`.
  * В результате алгоритм ошибочно вернёт `0` как минимальный элемент, хотя числа `0` вообще нет в исходном массиве (а реальный минимум равен `2`).
* **Правильное решение:** Инициализировать начальное значение переменной первым элементом массива (`int min = a[0];`) либо использовать индекс (`int minIndex = 0;`).
