# СРСП 2. Количество и сумма цифр числа

## 1. Псевдокод
```text
АЛГОРИТМ CountAndSumDigits
ВХОД: input (строка)
ВЫХОД: количество цифр (count) и их сумма (sum)

НАЧАЛО
    ВЫВЕСТИ "Введите целое неотрицательное число n:"
    СЧИТАТЬ input
    
    ЕСЛИ НЕ TryParse(input, n) ИЛИ n < 0 ТОГДА
        ВЫВЕСТИ "Ошибка: некорректный ввод"
        ЗАВЕРШИТЬ
    КОНЕЦ ЕСЛИ
    
    sum <- 0
    count <- 0
    
    ПОВТОРЯТЬ
        digit <- n MOD 10
        sum <- sum + digit
        count <- count + 1
        n <- n DIV 10
    ПОКА n > 0
    
    ВЫВЕСТИ count, sum
КОНЕЦ
