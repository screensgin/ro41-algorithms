# СРС 5. Трассировка рекурсивной функции

## 1. Базовый случай и шаг рекурсии
* **Базовый случай:** `if (n <= 1) return 1` — условие, при котором рекурсия останавливается и возвращается фиксированное значение (`1`) без новых вызовов.
* **Шаг рекурсии:** `return n * F(n - 1)` — уменьшение аргумента на единицу (`n - 1`), вызов функции от нового аргумента и умножение текущего `n` на полученный результат.

## 2. Ручная трассировка F(4)

| Вызов | Глубина стека | Описание / Процесс вычисления | Возвращает |
| :--- | :--- | :--- | :--- |
| `F(4)` | 0 | Ожидает результат `F(3)` | `4 * 6 = 24` |
| `F(3)` | 1 | Ожидает результат `F(2)` | `3 * 2 = 6` |
| `F(2)` | 2 | Ожидает результат `F(1)` | `2 * 1 = 2` |
| `F(1)` | 3 | Сработал базовый случай (`n <= 1`) | `1` |

## 3. Анализ вызова F(-1) при условии `n == 1`

Если заменить условие на `if (n == 1) return 1`, то при вызове `F(-1)` произойдет следующее:
1. Функция проверяет условие `-1 == 1`, которое дает ложь.
2. Происходит рекурсивный шаг к вызову `F(-2)`, затем `F(-3)` и так далее. Значение `n` уменьшается и уходит в область отрицательных чисел.
3. Поскольку аргумент отдаляется от целевого значения `1`, условие `n == 1` **никогда не будет достигнуто**.
4. Это приведет к **бесконечной рекурсии**, исчерпанию памяти под кадры вызовов и аварийному завершению программы с ошибкой переполнения стека **`System.StackOverflowException`**.
